# Project Brief: GRIDIRON RAW

## 1. Project Overview
**GRIDIRON RAW** is a high-octane, brutalist-style football(Soccer) blog designed for raw analysis and unfiltered commentary. The platform caters to die-hard football fans who prefer a stark, information-dense, and aggressive aesthetic over traditional corporate sports media.

## 2. Design Vision
*   **Style:** Brutalist / Industrial. High contrast, heavy borders, mono-spaced data points, and oversized typography.
*   **Color Palette:** Dark Mode Only. 
    *   Primary Background: `#131313` (Deep Charcoal)
    *   Accent: `#CCFF00` (Neon/Highlight Green)
    *   Secondary: `#FFFFFF` (Stark White)
*   **Typography:** Bold headlines (Anton) paired with technical, functional body text.

## 3. Core Features & User Stories
### 3.1 Authentication
*   **User Story:** As a fan, I want to create a "Callsign" (username) and register an account to access exclusive analysis.
*   **User Story:** As a returning user, I want to "Initialize Protocol" (login) securely to manage my posts.

### 3.2 Blog Feed & CRUD Operations
*   **Read:** Users can browse a "Breaking News" ticker and a grid of "The Trenches" (blog posts) with categories like Analysis, Opinion, and Data Room.
*   **Create:** Administrators/Users can initiate a "New Post" flow to contribute content.
*   **Update/Delete:** Post owners can modify or remove their contributions via integrated UI controls.

## 4. Technical Specifications
*   **Stack:** Vanilla HTML5, CSS3, and Vanilla JavaScript only.
*   **Responsive:** Initial focus on Desktop (1440px+), with mobile-responsive adjustments for the feed.
*   **Performance:** Lightweight, no-nonsense implementation to match the "Raw" brand identity.

## 5. Screen Inventory
1.  **Home Page (Feed):** Central hub for latest posts, trending topics, and site navigation.
2.  **Login Page:** Minimalist, secure entry point for authorized personnel.
3.  **Register Page:** Onboarding flow for "Joining the Squad."
4.  **Post Editor:** A dedicated interface for writing and formatting raw analysis.
4.  **Article View:** Deep-dive layout for long-form content.
